# Практикум по C#

Консольный практикум, задания 1–43.

## Запуск

```bash
dotnet run --project CSharpPracticum/CSharpPracticum.csproj
```

Выберите уровень, потом номер задания. `0` или `q` — назад или выход.

**Уровень 1.** Повторил условия, циклы, строки и массивы. Сложнее всего были сортировки и точный возраст.

**Уровень 3.** Попробовал HashSet, мемоизацию, сравнение коллекций, yield return, async/await и обработку ошибок.
